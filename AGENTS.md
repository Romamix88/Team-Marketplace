# AGENTS.md — Реестр агентов и MCP-серверов (команда Wildberries)

> Последнее обновление: 02 апреля 2026
> Инфраструктура: VPS (единый сервер) | LLM: RouterAI (routerai.ru)
> Фокус: автономная команда для управления кабинетом Wildberries

## MCP-серверы

### mcp-wb | MCP-сервер Wildberries
- **Статус**: ⚪ Планируется
- **Размещение**: VPS (Docker-контейнер)
- **Подключение**: Wildberries API v2/v3, Bearer token
- **Модули**:
  - [ ] Склады (`warehouses`) — Фаза 0
  - [ ] Аналитика (`analytics`) — Фаза 0
  - [ ] Цены (`prices`) — Фаза 1
  - [ ] Финансы (`finance`) — Фаза 1
  - [ ] Контент (`content`) — Фаза 2
  - [ ] Реклама (`advertising`) — Фаза 2
- **Инструменты по модулям**: см. ниже в разделе агентов
- **Используется агентами**: все 6 агентов WB

---

### mcp-1c | MCP-сервер 1С (отложен на Фазу 3+)
- **Статус**: ⚪ Отложен
- **Размещение**: VPS (подключается к 1С в офисе через WireGuard VPN)
- **Подключение**: HTTP-сервисы + OData, Basic Auth, HTTPS
- **Модули**:
  - [ ] Склад (`warehouse`) — остатки, себестоимость
  - [ ] Финансы (`finance`) — финансовые данные для сверки
- **Используется агентами**: agent-wb-logistics, agent-wb-analyst, agent-wb-accountant

---

## Агенты (команда Wildberries)

### agent-wb-manager | Руководитель маркетплейса
- **Статус**: ⚪ Планируется
- **Фаза**: 3
- **Размещение**: VPS
- **LLM**: Claude Opus 4.6 (через RouterAI) — сложная координация, принятие решений
- **Роль**: Точка контакта с владельцем. Получает цели, декомпозирует на задачи, распределяет между агентами, контролирует выполнение
- **Приоритет**: Внедряется после запуска первых 4 агентов
- **MCP-доступ**:
  - mcp-wb: все модули (чтение)
- **Инструменты**:
  - Создание и назначение задач другим агентам (через Redis)
  - Получение статусов выполнения задач
  - Формирование ежедневных/еженедельных сводок
  - Эскалация на человека при нестандартных ситуациях
  - Чат с владельцем (через Telegram-бот)
  - Анализ общих метрик кабинета WB
- **Human-in-the-loop**: Нет (координация), но эскалирует критичные решения владельцу

---

### agent-wb-logistics | Менеджер по логистике
- **Статус**: ⚪ Планируется
- **Фаза**: 1
- **Размещение**: VPS
- **LLM**: Claude Sonnet 4.6 (через RouterAI) — анализ данных, сопоставление
- **Роль**: Анализ остатков на складах WB, скорость продаж, формирование плана поставок
- **Приоритет**: 🔴 ВЫСОКИЙ
- **MCP-доступ**:
  - mcp-wb: warehouses (чтение + запись), analytics (чтение)
- **Инструменты**:
  - `wb_get_warehouse_remains` — остатки на складах WB (по товарам, по складам)
  - `wb_get_warehouses_list` — список доступных складов WB
  - `wb_get_sales_speed` — скорость продаж по товарам (шт/день)
  - `wb_get_supply_orders` — текущие заказы для поставки
  - `wb_create_supply` — создание поставки FBO (с подтверждением)
  - `wb_get_supply_status` — статус поставок
  - `wb_get_acceptance_coefficients` — коэффициенты приёмки по складам
  - Расчёт: дней до out-of-stock по каждому товару
  - Формирование плана поставок (товар, количество, склад, приоритет)
- **Human-in-the-loop**: Да — создание поставок

---

### agent-wb-content | Контент-менеджер
- **Статус**: ⚪ Планируется
- **Фаза**: 2
- **Размещение**: VPS
- **LLM**: Claude Sonnet 4.6 (через RouterAI) — генерация текстов, SEO, креатив
- **Роль**: Оптимизация карточек товаров для повышения CTR и конверсии
- **Приоритет**: 🔴 ВЫСОКИЙ
- **MCP-доступ**:
  - mcp-wb: content (чтение + запись), analytics (чтение)
- **Инструменты**:
  - `wb_get_cards_list` — список карточек товаров (nmId, артикул, название)
  - `wb_get_card_detail` — детальная информация по карточке (описание, характеристики, фото)
  - `wb_update_card` — обновление описания, характеристик карточки (с подтверждением)
  - `wb_get_card_stats` — статистика карточки (CTR, просмотры, добавления в корзину)
  - `wb_search_keywords` — поиск и анализ ключевых слов (частотность, конкуренция)
  - `wb_get_categories` — справочник категорий и характеристик WB
  - Анализ SEO: наличие ключевых слов в заголовке, описании, характеристиках
  - A/B тестирование: создание вариантов заголовков/описаний, замер CTR, выбор победителя
- **Human-in-the-loop**: Да — изменение контента карточек

---

### agent-wb-marketing | Маркетолог
- **Статус**: ⚪ Планируется
- **Фаза**: 2
- **Размещение**: VPS
- **LLM**: Claude Sonnet 4.6 (через RouterAI) — аналитика рекламы, оптимизация
- **Роль**: Управление рекламными кампаниями, удержание целевого CTR и ДРР
- **Приоритет**: 🔴 ВЫСОКИЙ
- **MCP-доступ**:
  - mcp-wb: advertising (чтение + запись), analytics (чтение)
- **Инструменты**:
  - `wb_adv_get_campaigns` — список рекламных кампаний и их статусы
  - `wb_adv_create_campaign` — создание рекламной кампании (с подтверждением)
  - `wb_adv_pause_campaign` — пауза кампании
  - `wb_adv_resume_campaign` — возобновление кампании
  - `wb_adv_get_stats` — статистика рекламы (показы, клики, CTR, CPC, расход, ДРР)
  - `wb_adv_set_budget` — изменение дневного бюджета (с подтверждением)
  - `wb_adv_set_bid` — изменение ставки за клик
  - `wb_adv_get_keywords` — ключевые слова кампании
  - `wb_adv_set_keywords` — управление ключевыми словами (добавление, минус-слова)
  - Автооптимизация: корректировка ставок для удержания целевого ДРР
  - Анализ эффективности: ROI по кампаниям, рекомендации по перераспределению бюджета
- **Human-in-the-loop**: Да — создание кампаний, изменение бюджета

---

### agent-wb-analyst | Аналитик
- **Статус**: ⚪ Планируется
- **Фаза**: 1
- **Размещение**: VPS
- **LLM**: DeepSeek V3.2 (через RouterAI) — структурированный анализ, экономия
- **Роль**: Анализ продаж, маржинальности, рекомендации по ценам и действиям
- **Приоритет**: 🔴 ВЫСОКИЙ
- **MCP-доступ**:
  - mcp-wb: analytics (чтение), prices (чтение + запись), finance (чтение)
- **Инструменты**:
  - `wb_get_sales_report` — отчёт о продажах за период (по товарам, по дням)
  - `wb_get_orders` — заказы за период (статусы, суммы)
  - `wb_get_returns` — возвраты (причины, суммы)
  - `wb_get_prices` — текущие цены на все товары
  - `wb_set_prices` — изменение цен (с подтверждением)
  - `wb_get_discounts` — текущие скидки
  - `wb_get_competitors_prices` — цены конкурентов на аналогичные товары
  - `wb_get_financial_report` — финансовый отчёт (выручка, комиссии, логистика)
  - Расчёт unit-экономики: выручка — комиссия WB — логистика — хранение — себестоимость = прибыль
  - Рекомендации: повысить/понизить цену, вывести из ассортимента, усилить рекламу
- **Human-in-the-loop**: Да — изменение цен

---

### agent-wb-accountant | Бухгалтер
- **Статус**: ⚪ Планируется
- **Фаза**: 3
- **Размещение**: VPS
- **LLM**: DeepSeek V3.2 (через RouterAI) — сверки, структурированные данные, экономия
- **Роль**: Сверка финансовых документов WB, контроль комиссий и штрафов
- **Приоритет**: 🟡 СРЕДНИЙ
- **MCP-доступ**:
  - mcp-wb: finance (чтение), analytics (чтение)
- **Инструменты**:
  - `wb_get_financial_report` — детализированный финансовый отчёт WB (по неделям)
  - `wb_get_paid_storage` — стоимость хранения по товарам
  - `wb_get_penalties` — штрафы и удержания (причины, суммы)
  - `wb_get_commissions` — комиссии по категориям товаров
  - `wb_get_returns_cost` — стоимость возвратов (логистика, компенсации)
  - Сверка: данные WB-отчётов vs данные аналитика → выявление расхождений
  - Формирование еженедельного финансового отчёта для руководителя
  - Мониторинг аномалий: резкий рост штрафов, нетипичные комиссии
- **Human-in-the-loop**: Нет (только чтение и анализ)
